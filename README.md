# Project HabitFlow

HabitFlow is a website that helps users build and maintain positive daily habits. Users can create personal habits, check them off each day, and monitor their consistency through streaks and completion statistics.

## Styling and Responsive Design

The team set out to build a theme for selectors within `style.css` as an initial template for general use across styling. The team iteratively improved `style.css` as needed and implemented responsiveness via the use of `@media` queries within `style.css`. Additionally, the team implemented classes and identifiers to handle the nuances of some pages, such as the use of `div` with a grid layout instead of a `table`.
